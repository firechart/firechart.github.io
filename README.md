# firechart.github.io

The site of the FireChart organization: <https://firechart.github.io/>. Plain HTML and CSS, no build; GitHub Pages serves the branch `main`
as it is (`.nojekyll`).

- `index.html`: the home page, with links to [FireChart Viewer](https://firechart.github.io/viewer/) (its own repository,
  [firechart/viewer](https://github.com/firechart/viewer), served at `/viewer/`).
- `assets/site.css`, `img/firechart-logo.svg`: the style and the logo of the site of the Viewer, copied.
- `robots.txt`: the one of the whole host `firechart.github.io`, the pages of the Viewer included; `sitemap.xml`.
